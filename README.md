# tridennote/homebrew-tap

Homebrew formulae for [Tridennote](https://github.com/tridennote/cli).

```bash
brew install tridennote/tap/tridennote
```

`Formula/tridennote.rb` is regenerated from the latest GitHub release's `checksums.txt` by
`scripts/update-formula.sh`. The **Update formula** workflow runs it every 6 hours, on
demand (`gh workflow run update-formula.yml -R tridennote/homebrew-tap`), or when it
receives a `tridennote-release` repository dispatch.
